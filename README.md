Flex Chat is a real-time chat application developed as part of an internship assignment at Mindfire Solutions.

**Tech Stack:**
- **Frontend:** React.js
- **Backend:** ASP.NET Core Web API, SignalR for real-time communication
- **Database:** Microsoft SQL Server (SSMS)
- **Data Access:** LINQ

**Architecture:**
The backend follows a layered architecture with separate API, Business Logic, and Database layers to improve separation of concerns, maintainability, and code organization.

The project demonstrates practical implementation of full-stack development concepts, real-time messaging, API development, database integration, and structured backend design.
